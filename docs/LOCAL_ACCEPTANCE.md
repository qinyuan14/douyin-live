# V1 本地验收状态

核验时间：2026-08-14（Asia/Shanghai）

## 已验证

- 本地服务只监听 `127.0.0.1:3188`；除健康检查外，所有读写接口都需要每次启动新生成的本机桌面令牌。
- 商品、正式证据、经营记录、订单哈希和时间顺序均有运行时校验。
- 60段流程共7200秒，话术不重复；过期、空证据、永久禁止表达、特殊材质及缺少专项证据的功效词不能进入批准段落。
- 普通知识接口只能保存为高风险人工草稿；自动播报只认安装时锁定、内容指纹一致、由本工具登记且未过期的白名单，未登记文件和完整隐私不能进入流程表或问答播报。
- 暂停、停止、本机服务断线、摄像头中断和场次状态不符时，输出端取消并拒绝AI播报。
- 证据文件由程序保全到本地证据库并自动计算SHA-256；文本文件会拦截常见完整隐私，图片和PDF要求员工先脱敏并确认；退款损失不会从批次贡献中排除。
- 语音门禁需要系统播放后由值班员工亲耳确认；新客候选需要人工核对历史订单并分别保全已脱敏的新客证据与结算成本证据。
- 文件存在与指纹匹配只证明证据未变化，不证明内容真实；官方答复、成本和素材授权始终保留人工复核，经营模块也只给“量化门槛候选”，不会自行宣称已赚钱。
- `pnpm check` 通过：代码检查、严格类型、31项自动测试和正式构建通过。
- 1轮5秒短时压力烟测通过；安全依赖扫描未发现已知高危漏洞。
- 控制台和竖屏输出完成本机截图检查；预览为精确9:16，已生成1080×1920验收图和平台操作安全区图。
