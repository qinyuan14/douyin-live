本地经营工具 · 非数字人挂机

实景直播经营系统

用真实作业现场 + AI 小助手主持 + 白名单问答与人工兜底，帮你把直播人力降下来，并把付款追踪到履约与复购。

1这是什么？

  • 1080×1920 竖屏实景输出窗口 + 独立员工控制台，双窗口协作
  • 首次启动向导：填写你的品牌名、真实服务范围与商品类目（不内置任何行业模板）
  • 两小时非循环 AI 流程表、本地中文语音、字幕与商品提示
  • 开播硬门禁：书面确认、服务范围、完整成本、设备、素材、当次授权——缺一不开播
  • 经营闭环：付款 → 履约 → 完成 → 复购 → 成本，全部本地留存、可复核、可备份恢复
定位：它不会自动登录、自动开播、抓弹幕、模拟点击或改价。平台账号、价格、资金和开播动作始终留在你手中，本系统只做本地验证过的合规内容自动播报。

2购买与激活

本工具为付费软件，首次使用需要输入授权码激活：

  1. 启动软件后，在激活界面复制本机机器码，发给卖家
  2. 卖家根据你的机器码生成激活码（例如 v1.xxxxxxxx.0000000000.签名）
  3. 把激活码粘贴到激活界面，完成激活即可使用
⚠️ 授权码与这台电脑一一绑定——拷贝激活文件到别的电脑无效（防复制传播）。
换电脑 / 重装系统后需要重新激活，请联系卖家重新生成。

3本地启动（开发/自用）

  • 环境要求：Windows 10/11，Node.js 24.16+，pnpm 11.5.0
  • 开发模式：pnpm install 后 pnpm dev——会打开员工控制台和竖屏直播输出两个窗口
  • 生产构建：pnpm check 验证，pnpm start 运行
API 仅监听本机 127.0.0.1:3188；每次启动生成新的本机身份令牌，没有本次令牌的网页或程序不能读取或写入你的经营数据。

4安全说明（重要）

  • 本系统不会登录抖音、开播、挂商品、改价、退款、核销、私信或投流
  • 首版不读取抖音弹幕；员工在控制台选择问题类型或输入脱敏问题
  • .data/ 内是本地工作记录，不是公司经营权威台账
  • 上传的证据必须先人工脱敏；文本证据会再做常见隐私检查
  • 员工或外部程序新增的知识只能作为待复核草稿，不能直接进入自动播报；自动播报只使用安装包内锁定且证据登记一致的白名单知识
  • 没有平台规则书面确认、完整成本、摄像头和当次开播授权时，正式开播状态保持阻断
必须在抖音直播伴侣预览中确认 1080×1920 画布采集稳定，未通过前不得真实开播。

5商家需知（开播前置条件）

平台规则书面确认当前账号、商品和履约方式对应的官方书面答复
服务范围确认在初始化向导中确认真实可执行的服务范围
完整成本平台净结算、履约、生产、耗材、值守、返工、售后成本
设备验证摄像头、语音、虚拟音频、人工声音接管通过预览验证
素材权利素材权利和 AI 标识通过审核
当次授权对具体账号、商品、日期和开播动作取得当次明确授权
6 项硬门禁全部满足前，系统状态保持「本地商用候选」，仅允许本地演练与直播伴侣预览。
