# 猫掌柜 AI 实景直播经营系统

面向洗鞋洗护门店的 Windows 本地直播经营工具。它用真实洗护台画面、黑猫掌柜 AI 主持、白名单问答和人工风险兜底降低直播人力，并把付款追踪到履约、复购和完整成本。

当前状态：**本地商用候选，未连接抖音账号，未开播，未验证真实赚钱。**

## 本地启动

环境：Node.js 24.16.x、pnpm 11.5.0、Windows 10/11。

```powershell
pnpm install
pnpm dev
```

开发模式会先生成共享代码，再打开员工控制台和竖屏直播输出两个窗口。API仅监听 `127.0.0.1:3188`。每次启动会生成新的本机桌面身份令牌；除健康检查外，没有本次令牌的网页或本机程序不能读取或写入经营数据。

生产构建与本地运行：

```powershell
pnpm check
pnpm start
```

## 安全说明

- 本系统不会登录抖音、开播、挂商品、改价、退款、核销、私信或投流。
- 首版不读取抖音弹幕；员工在控制台选择问题类型或输入脱敏问题。
- `.data/` 内是本地工作记录，不是公司经营权威台账。
- 上传的证据必须先人工脱敏；文本证据会再做常见隐私检查，图片和PDF内容仍由值班员工负责确认。
- 员工或外部程序新增的知识只能作为待人工复核草稿保存，不能直接进入自动播报；自动播报只使用安装包内锁定且证据登记一致的白名单知识。
- 新客、语音线路和证据内容不能由程序自行证明，必须保留员工确认和后续独立复核。
- 没有书面客服证据、完整成本、摄像头和当次开播授权时，正式试播状态保持阻断。
- 当前已生成1080×1920验收图，但本机 Windows 原生窗口被工作区限制为540×960预览；必须在抖音直播伴侣预览中确认其1080×1920画布采集稳定，未通过前不得真实开播。
- 正式试播仍需补齐“具体账号、商品、日期、动作”的当次授权流程；V1不会自动把该项解锁。
