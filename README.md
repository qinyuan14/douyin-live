# 实景直播经营系统

一款面向本地服务商户的 Windows 桌面直播经营工具：用**真实作业现场画面** + **小助手 AI 主持** + **白名单问答**与**人工风险兜底**降低直播人力，并把付款追踪到履约、复购和完整成本。

**定位**：这不是数字人播放器。它不登录、不抓取、不模拟点击；只做本地验证过的合规内容自动播报，人工始终掌握开播动作。

## 特性

- 1080×1920 竖屏实景输出窗口 + 独立员工控制台（双窗口）
- 首次启动向导：填写你的品牌名、真实服务范围与商品类目（不再内置任何行业模板）
- 离线授权：授权码绑定本机机器码，防复制传播，一次购买本机永久使用（过期需续期）
- 两小时非循环 AI 流程表、本地中文语音、字幕、商品提示
- 开播硬门禁：平台规则书面确认、服务范围确认、完整成本、摄像头/语音/接管、素材授权、当次开播授权
- 经营闭环：付款 → 履约 → 完成 → 复购 → 成本，全部本地留存、可复核、可备份恢复

## 购买与激活

本工具为付费软件，首次使用需要输入**授权码**激活。

1. 启动软件后，在激活界面**复制本机机器码**，发给卖家。
2. 卖家根据你的机器码生成**激活码**（例如 `v1.xxxxxxxx.0000000000.签名`）。
3. 把激活码粘贴到激活界面，完成激活。

> 授权码与这台电脑一一绑定，**拷贝激活文件到别的电脑无效**（防复制传播）。
> 换电脑 / 重装系统后需要重新激活，请联系卖家重新生成。

### 卖家（开发者）生成激活码

```bash
# 首次：生成密钥对（私钥必须妥善保管，已 gitignore，严禁提交）
node scripts/license/generate-keypair.mjs

# 为买家机器码生成激活码（默认 10 年，可按需指定天数）
node scripts/license/generate-license.mjs <买家机器码> [有效天数]
```

## 本地启动（开发）

环境：Node.js 24.16.x、pnpm 11.5.0、Windows 10/11。

```powershell
pnpm install
pnpm dev
```

开发模式会先生成共享代码，再打开员工控制台和竖屏直播输出两个窗口。API 仅监听 `127.0.0.1:3188`；每次启动生成新的本机桌面身份令牌，除健康检查外，没有本次令牌的网页或本机程序不能读取或写入经营数据。

生产构建与本地运行：

```powershell
pnpm check
pnpm start
```

## 安全说明

- 本系统不会登录抖音、开播、挂商品、改价、退款、核销、私信或投流。
- 首版不读取抖音弹幕；员工在控制台选择问题类型或输入脱敏问题。
- `.data/` 内是本地工作记录，不是公司经营权威台账。
- 上传的证据必须先人工脱敏；文本证据会再做常见隐私检查，图片和 PDF 内容仍由值班员工负责确认。
- 员工或外部程序新增的知识只能作为待人工复核草稿保存，不能直接进入自动播报；自动播报只使用安装包内锁定且证据登记一致的白名单知识。
- 新客、语音线路和证据内容不能由程序自行证明，必须保留员工确认和后续独立复核。
- 没有平台规则书面确认、完整成本、摄像头和当次开播授权时，正式开播状态保持阻断。
- 必须在抖音直播伴侣预览中确认 1080×1920 画布采集稳定，未通过前不得真实开播。
